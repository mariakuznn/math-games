# math-games

Браузерные игры по высшей математике. Каждая открывается по ссылке, ничего устанавливать не нужно. Играть можно на компьютере и на телефоне.

Игры сделаны как интерактивные уроки к моим курсам: математика в них не проверка знаний между уровнями, а сама механика игры.

## Игры

| Игра | Тема | Сыграть |
|---|---|---|
| **Кот Лейбниц** | Производные функции одной переменной | [kot_leibniz.html](https://mariakuznn.github.io/math-games/kot_leibniz.html) |
| **Туман** | Частные производные, производная по направлению, градиент, линии уровня, дифференциал, критические точки | [tuman.html](https://mariakuznn.github.io/math-games/tuman.html) |
| **Десять дверей** | Частные производные и градиент | [dveri.html](https://mariakuznn.github.io/math-games/dveri.html) |

### Туман

Вы сидите за пультом в кафе на краю математической зоны и по рации ведёте путника, застрявшего на планете-свалке. Из низин поднимается ядовитый туман, а у вас есть только экран с его датчиков и модуль наклона. Чтобы вывести путника к сигнальной башне, нужно считать частные производные, находить градиент, отличать локальный максимум от настоящей вершины и проходить через седловую точку. По ходу маршрута 10 задач на вычисления.

### Десять дверей

Блочный 3D-коридор заброшенного архива. Каждую дверь держит замок, и открывает его только правильная частная производная или градиент. Иногда по коридору проходит Гул: когда мигает свет, нужно быстро ответить на вопрос и спрятаться в шкаф. Числа в задачах при каждом запуске новые.

## Для кого

Для студентов, которые изучают математический анализ, и для всех, кто хочет вспомнить его в необычном формате. Понадобятся бумага и ручка.
